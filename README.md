## 体験と設計

成人向けのエンタメ性癖診断。添付の `nocturne.html` を視覚の基準に、短い24場面と五つの選択肢を持つ一つの診断へ変更しました。最初の自己イメージだけ一択、その後は惹かれる内容を最大二つ選びます。「今回はなし」と保留は別に記録し、避けたいことは四つとも選べます。順番・選択数・性別・年代・気分から強さを加点しません。未回答を中間点やゼロへ変換しません。主導・委ね・翻弄する側・される側・甘やかす側・甘える側を独立に選べます。香り・温もりと触れ合い、自由を預かる側・預ける側、痛みのある刺激を与える側・受ける側も、複数の場面で確認します。

候補成分や二つ名は初期仮説です。性癖の完全な網羅、無意識の測定、心理検査としての妥当性、関係の成功率は主張しません。繰り返した選択と回答の機会を見て名前を作り、一つの選択だけで強い結論を出しません。16の関係性は、診断の分類数ではなく読みものの図鑑です。

開始時の身体視点・年代・気分は必須選択とし、回答提供へ明示的に同意してから始めます。30代・40代・50代は前半と後半を分け、60歳以上を独立に選べます。回答数と人数は区別し、同じアカウントの複数回答は人数では1人として集計します。別ブラウザー・別端末では、同じ引き継ぎキーでログインした場合に同じアカウントとして扱います。

入口、質問、カルテを画面内に収める構成。結果は名前・好み・接し方・記録・共有の5ページです。小さい高さや拡大時には内容を切らずにスクロールを許します。動きを抑える設定にも対応します。質問の日本語は場面と希望を保って短くし、BudouXと保護する語句で改行を整えます。診断画面に内部の点数や運用仕様は出しません。

## 主なファイル

- `src/nocturne.mjs`: 24場面、選択肢、独立した希望、二つ名、公開用カルテ、比較。
- `src/app.mjs`, `src/app.css`: 端末保存、画面、履歴、共有、匿名募集。
- `src/nocturne-v1.mjs`, `src/nocturne-v2.mjs`: 以前の24場面の結果を当時の言葉で残す読み取り用の定義。診断の別コースには使いません。
- `src/vault.mjs`: アカウントごとの端末の記録を分離。切り替えで履歴や自由な言葉を混ぜません。
- `src/nocturne-service.mjs`, `migrations/0005*`, `0006*`: D1の記録、ログイン、短いURL、募集、相互反応、ブロック、通報、集計、期限処理。
- `src/diagnosis.mjs`, `src/share-compat.mjs`, `src/share-v5.mjs`: 当時のH4/H5/H6共有を読み取る互換処理。過去の診断コースは画面に出しません。
- `src/worker.mjs`: 新しいAPIと既存の回答提供・撤回を配信。以前の提供の削除機能を残します。
- `src/metrics.mjs`, `src/metrics-service.mjs`, `migrations/0007*`: 回答と分離した匿名の訪問・操作計測と日別集計。
- `src/admin-report.mjs`, `src/admin-ui.mjs`, `src/admin-worker.mjs`: 所有者限定の全保存期間の分析とCSV出力。
- `scripts/analytics.cjs`, `scripts/moderate.cjs`: Cloudflare認証を持つ運営者だけが使う分析と掲載管理。管理画面は所有者だけが閲覧できます。

`dist/` は生成物。`sources/`などの同期資料や、Downloadsの添付HTMLは変更しません。

## 記録とログイン

開始前の一画面で、回答の目線・気分・年代・性別と成人確認・回答提供の同意を確認します。属性は未選択のまま開始できず、「回答しない」も明示して選べます。320px幅でも選択欄と開始ボタンが収まるようにしています。提供せず端末だけで試す経路もあります。試したあとでも、選んだ回答を変えずに同意して記録し、共有や匿名募集へ進めます。同意後は登録画面を挟まずに匿名の記録を作り、HttpOnly・Secure・SameSite=StrictのCookieで本人の履歴だけを読み書きします。引き継ぎキーは本人が発行を選んだときに一度だけ表示し、保存先にはハッシュだけを残します。別の端末からキーでログインできます。キーは共有URLとは別です。

回答は4場面ごと・中断時・完了時に同期し、通信できない間は端末に残します。古い更新が新しい更新を上書きせず、完了した記録を変更しません。アカウント切り替え時は同期を中断し、端末の記録を分離します。API側でも更新対象の所有者とアカウントの一致を確認します。

「普段の好み」「今の望み」は同じ質問票の時間の文脈です。気分や時間帯は記録し、結果を補正する材料にはしません。履歴に架空の過去や仮の基準点を作らず、同じ質問票と文脈の実際の記録を比べます。以前の結果は保存済みの文章を使い、以前の途中回答は端末内に残して新しい質問へ読み替えません。

## 短いURLと匿名募集

共有は画像で内容を確認してから、`/s/`と96bitのランダムな識別子を持つURLを発行します。公開用の二つ名・短文・説明・選んだ3タグと主な好みだけを保存し、個別回答、年代、性別、履歴を含めません。共有リンクはnoindex・no-storeで、90日で期限が切れます。

匿名の募集一覧は、提供した診断を完了し、半分以上の場面に回答した利用者が閲覧できます。本人が選んだカルテだけを明示同意後に7日間掲載します。掲載する二つ名と好みを事前に表示し、年代・性別は掲載時に追加で選ぶ方式。自由タグ・自由な募集文・写真・場所・連絡先・DMは公開しません。

共通する好み、役の組み合わせ、個別の好み、相手の目的、公開された年代・性別で絞れます。双方が「気になる」を選ぶと掲載したカルテ同士を比較します。成功率は出しません。掲載の撤回、更新、ブロック、期限切れで相互反応を無効にします。非表示は本人の管理画面から解除できます。通報は相手を非表示にし、3人からの通報で掲載を確認待ちにします。再掲載や通報者の削除で確認待ちを回避できない状態を保持します。

## 分析と運営

管理者: https://nocturne-admin.aiyume.workers.dev/

所有者向けの管理画面はD1を直接集計します。対象は保存されている全期間・全件で、直近7日や新しい2,000件で打ち切りません。日付（日本時間）、質問票、同意時期、年代、性別、気分、回答の目線、時間帯で絞り込み、質問ごとの閲覧・回答・該当なし・未回答・中断位置・滞在中央値/90%点・選択肢、好み・二つ名、属性群別の傾向とCSVを確認できます。中断は30分以上進んでいない状態で、離脱の確定ではありません。回答時間は完了記録の場面滞在時間の合計です。

`nocturne-2026-10-21`の案内以降に提供された回答は、所有者が1人からの属性・好みを確認できます。従来の同意（`nocturne-2026-10-19`）は当時の説明を維持し、好み・属性・二つ名など5人未満の値を伏せます。旧クライアントや途中の記録の同意を自動で切り替えません。各人の最新結果を使う好みの分布と、診断単位の完了・二つ名件数を区別しています。少人数から一般人口の割合、因果関係、マッチングの成功率は推定しません。集計から質問や分類を自動で書き換えません。

訪問はこの版の計測開始以降を対象にします。それ以前は未測定（null）で、0とは表示しません。30分のタブ単位で重複を除いた訪問と、開始画面・診断開始/完了・共有画面/リンク発行/X画面・募集閲覧/掲載/反応を計測します。実人数、実際のX投稿、利用者の離脱理由の断定には使えません。DNT/GPCの指定とCloudflareが識別した既知Botは計測を省きます。

訪問は回答・属性・アカウントと結び付けず、IP、完全な参照URL、共有IDを保存しません。訪問元は検索/SNS/直接・不明/その他、画面はスマホ幅/大きい画面に丸めます。ランダムな計測IDのハッシュを重複防止用に2日間保持し、その後も日別の匿名集計を保持します。訪問元・画面の条件は訪問集計だけに適用します。回答の属性で訪問を絞ったと誤認しないよう、画面に母集団の違いを表示します。

以前からの15分ごとのR2非公開`owner/nocturne-current.json`は、直近7日・2,000件以内の運営用スナップショットとして残します。この制限は回答の収集や新しい管理画面の分析範囲にはかかりません。従来の`npm run analytics`も、このスナップショットを読む補助手段です。

```sh
npm run analytics
npm run moderate -- list
npm run moderate -- hide <掲載IDまたは管理ID>
npm run moderate -- dismiss <掲載IDまたは管理ID>
```

管理者画面は公開アプリと別のWorker（`wrangler.admin.jsonc`）で運用します。Cloudflare Accessで所有者のメールだけを許可し、WorkerでもAUDと所有者メールを検証してからD1の集計を読みます。`ADMIN_EMAIL`はWorkerのシークレットとして設定します。画面・スクリプト・集計APIすべてで認証を行い、回答の生データを返しません。公開サイトに管理者への導線は置きません。端末内で確認する場合は従来の`npm run analytics`も使えます。

## myfansの導入準備

登録・媒体審査・広告物の掲載前確認・生成リンク取得は未完了で、広告は無効です。[登録の準備と有効化手順](docs/MYFANS_PREPARATION.md)に必要情報と媒体説明案をまとめています。本人確認・口座などはリポジトリやチャットに置かず、本人が公式画面で入力します。

`config/monetization.json`の媒体承認と各広告の文言承認・リンク確認・再確認期日をビルドで検証し、未承認の広告は公開カタログへ出しません。広告は本人の結果の共有ページと共有準備後から、PR入口を押した場合だけ一件ずつ表示します。診断中、結果の名前、共有画像、受け取った結果や見本、匿名募集には入れません。リンクに回答・属性・識別子を追加せず、外部の画像や計測タグを読み込みません。

回答に応じた表示調整は別の任意設定で、初期値はオフです。`personalizationEnabled`を承認後に有効にし、本人がPR画面で選択した当該診断だけ、端末内の強く選ばれた好みと承認済み広告の`affinities`から表示順を調整します。過去の提供同意を広告利用に読み替えず、年代・性別・自由タグ・履歴は使いません。設定は診断IDごとで30日間、オフへの切り替えと端末データ削除で解除します。DNT/GPCがある場合は通常表示にし、PR操作も計測しません。

PR表示・クリックは既存の匿名集計へ加え、30分のタブ単位で重複を除きます。キャンペーンIDや広告選別の情報を計測に送りません。購入・到着・確定報酬はmyfans側のレポートで確認し、NOCTURNE側に売上や成果を推測で表示しません。

## 保存期間・復旧・費用

完了回答は開始から180日、途中の記録は最終更新から30日、ログイン状態30日、共有90日、募集7日、長期間使われないアカウント1年を目安に削除します。回答提供の撤回はアカウントに属する回答・履歴・ログイン状態・共有・掲載を削除します。R2の回答を含まない削除の控えを先に保存し、失敗時に削除済みと表示しません。

D1の復旧前は`RECOVERY_MODE`を新しいUUIDにして受付・共有を止めます。以前の`withdrawals/`に加え、`nocturne-withdrawals/`と`nocturne-record-withdrawals/`を再適用します。各`nocturne-recovery/<UUID>/`の完了と、既存の`maintenance`の完了を確認してから停止を解除します。画面のロールバックにD1の巻き戻しは不要です。

Turnstileの成功・hostname・action、Originと専用ヘッダー、本人の所有権をサーバーで確認します。本文8KiB、個別10回/分、拠点ごと120回/分、日500診断開始・10,000書込みの正確な上限を持ちます。書込み上限はSQLiteのトリガーで制御し、再試行で越えられません。CPUは最大250ms。訪問計測は別枠で30回/分、日20,000イベントの正確な上限を持ち、診断の書込み枠を消費しません。管理APIは所有者にも10回/分の制限をかけます。全件の分析はSQLの集計を返し、生の回答をブラウザーへ取り出しません。生成AIや従量課金の外部AI APIは使いません。これらはアカウント全体の月額を5ドルに固定する保証ではありません。

`RESEARCH_ENABLED=false`で新しい受付・更新・掲載を止められ、撤回・非表示・ログアウトは続けられます。未取得の広告IDは有効にせず、診断中に広告を出しません。

## 検証の境界

実画面と操作はスマホ幅320/390・デスクトップ幅で検証します。実機Safari、実利用者の納得感、継続率、Xでの拡散効果、出会い・連絡機能の運営要件は別の確認事項です。今回は匿名カルテの発見と比較までを扱い、本人確認を伴う出会い系サービスの提供を主張しません。

## 公開先の移転

公開先は `https://nocturne.ai-yu-me.com/` です。以前の `heki16-pro` は `wrangler.move.jsonc` と `src/move-worker.mjs` で移転先へ案内し、定期集計は新しいWorkerだけが実行します。D1/R2は移転前と同じ保存先を使います。

以前の共有リンクは識別子を保って新しいサイトへ案内します。ログインCookieと端末だけの記録はホストをまたいで読めないため、`https://heki16-pro.aiyume.workers.dev/?records=1` で引き継ぎキーの発行と以前の結果の閲覧を続けられます。公開UIには移転案内を表示しません。キーや回答をURLに埋め込みません。旧サイトの受付を止めるときも、撤回と引き継ぎの経路は残してください。

「名前だけ」の共有は画像だけでなく、保存する公開カルテから説明・タグ・詳しい好みを取り除きます。年代や性別から回答や結果を補正しません。時間の比較は同じ質問票・同じ時期の区分で答えた過去の実記録に限り、未回答を0へ置き換えません。
