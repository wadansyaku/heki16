# HEKI-16 PRO

Version 16.64.3. 添付版 16.64.2 と引き継ぎ指示をもとにした開発継続版です。

## 使い方

`dist/index.html` をブラウザで開くだけで動きます。ローカルで同じ保存領域を使い続ける場合は、`npm run serve` で `http://127.0.0.1:8766/` を開いてください。配布HTMLにはCSS・Chart.jsを同梱しており、診断や画像生成に外部CDNは不要です。

回答・診断結果は端末の localStorage にのみ保存します。相手・グループの入力は送信・保存しません。診断はエンタメであり、医療的診断・相手の同意や行動の予測には使いません。

## 変更点

- 32問すべての情景選択。7段階は同じ対象への親和度として並び、否定回答を逆属性への肯定として扱いません。
- 8軸とクールさをそれぞれ算出し、S/MおよびW/Cが同時に高く・低くなる状態を保持。
- 3〜4人の相関図、対等な関係・同率の扱い、PNG出力。
- 16タイプ × 4サブタイプ × 12ロールに応じた768通りの情景ノート。
- 途中回答の再開、モード切替時の共通回答の引継ぎ、未回答のまま確定する操作の防止。
- 名前・推しタグ・NGタグの保存、旧保存データの検証・移行。見本の閲覧で実際の保存結果を上書きしません。
- 120%と双極特異点コードを保持する共有コード。従来の4文字・旧2桁の共有コードも読めます。
- 診断画面の測定ラベルを削除。スマホの4タブ、結果の5サブタブと3テーマ×2サイズのPNG出力を維持。
- 根拠のない出現率表示を削除。

## 共有コード

旧形式 `DWNX-O-9634-9492-6490-9874` と `DWNX-8842-7590` を受け付けます。新形式ではペアごとに3桁を使い、例 `XWAX-O-120107-107109-120109-107107-C093` のように0〜120の8軸と独立したC値を保持します。Xで始まるコードからはS/Mの実測値でD/Sのベースタイプを復元します。不正な文字列や範囲外の数値を黙って既定値に置き換えません。

旧版ですでに99に丸められた値や、保存されていないC値は復元できません。旧診断の8軸はそのまま引き継ぎ、Cが未保存の場合のみ中立値62を使います。新しい質問表現と独立Cの計算が必要な場合は再診断してください。

## 開発・検証

Node.js 22以降で `npm test`。追加パッケージのインストールは不要です。テストは64分類のコード往復、独立軸、未回答拒否、保存移行、768通りの情景、3人・4人相関図、同率の扱いを確認します。

正規の公開設定は `.openai/hosting.json` です。現在の公開範囲はオーナー限定です。ソースをGitHubに更新しただけでは、公開版は変更されません。公開時には同じSiteに対して検証済みコミットを保存・反映してください。
