## コンテンツと画面

「自分がしたい・されたい」を中心とする40問・16タイプのエンタメ性癖診断です。主導・委ねとS/Mの反応を分け、共依存、温度差、文脈、属性、背徳、甘やかしの併存を残します。裏スイッチと自動タグは複数の回答から作ります。独自仮説であり、医学的検査や関係の成功率ではありません。

質問は意図した5章の順番で固定します。場面に慣れる→関係の距離→ギャップと五感→甘さとスリル→具体的な場面、の順です。36問の強さの回答と4問の場面選択を持ち、場面の選択肢に序列点を付けません。再開・戻る・見直しでも同じ並びです。質問順による影響や人間の納得感は未検証です。

主画面はタイプ名、短い発見、三つの刺さる要素を中心にし、詳細は開いて読みます。グループ比較は最大4人・6組を折りたたみます。単色の配色、短い状態変化のアニメーション、reduced-motion対応。判定係数、版の選択、運用条件を利用者向け画面に出しません。

- `src/content.mjs`: 正本となる40問、選択肢、10指標の主項目、16タイプの名称と説明。
- `src/diagnosis.mjs`: 独立した得点、タイプ、裏スイッチ、共有、二人の組み合わせ。
- `src/tags.mjs`: 自由タグの正規化、分類、本人による分類修正の保持。
- `src/index.html`, `src/home.html`, `src/app.css`, `src/app.mjs`: 画面、操作、端末保存、共有画像。
- `src/worker.mjs`, `migrations/`: 任意提供の受付・撤回、集計と期限処理。
- `scripts/build-content.cjs`, `scripts/prepare-deploy.cjs`: 同じタイプ辞書から26ページを生成し、CSP・公開範囲・ハッシュを確認。
- `src/legacy.html`, `src/reflection.mjs`: 非公開の履歴資料と回帰検証用。配信しません。`/legacy/` はトップへ誘導します。

`dist/` は生成物です。生成元を編集してください。

## 保存と共有の互換性

回答は `heki16_unified40_v1` に保存します。以前の保存領域は上書きせず、自由タグを引き継ぎます。以前の回答を40問の回答へ変換せず、公開の診断コースは一つにします。

H4共有コードは指標ごとの合計・回答数・強い回答数、補助情報、タイプ、選んだ最大3タグを含み、40問の個別回答を含めません。受け取った結果は自分の結果として保存しません。比較する相手の共有情報はsessionStorageで一時保持し、再開・再読込で消失しないようにします。共有URLを知る人は結果を読めます。

D1の `diagnosis_submissions` に40問の任意提供を保存します。既存の `submissions` を残し、過去の提供の撤回を維持します。両テーブルは日500件の同じ受入枠と変更版を使い、IDを使った過去の撤回の妨害も拒否します。新しい提供のAPIは現行40問のみを受け付けます。

## 任意提供と自律処理

通常の診断・タグ・共有画像は端末で処理します。18歳以上の本人が同意した場合だけ、数値回答とタグ分類ごとの個数を提供できます。名前、自由タグ本文、連絡先は受け取りません。

15分ごとの定期処理で180日を超えた回答を削除し、直近14日から日140件、最大1,960件を点検します。現行質問の未回答、分布、項目間の関係を私的なR2レポートへ保存します。場面選択に序列の平均を付けません。未知の統計はnullです。

参考値の公開には200件、7日、全回答・回答の多様性等の運用条件を設けます。これは検証済み尺度を意味せず、同一人物の複数回答も完全には排除しません。αは診断用の分類を自動変更する条件にはしません。集計が育っても、質問・重み・タイプ名は黙って書き換えません。

R2には個人回答を置かず、集計、品質レポート、回答を含まない削除記録を保管します。公開用の集計とDBの変更版が不一致なら返しません。削除・計算失敗・復旧中も公開を閉じます。削除記録の有効期限は31日です。

復旧前は `RESEARCH_ENABLED=false` と新しいUUIDの `RECOVERY_MODE` を設定して再公開し、復旧したデータへR2の削除記録を再適用します。`maintenance` の `recovery_complete` と整合を確認してから戻します。両テーブルの撤回に対応するWorkerを維持してください。画面を戻すためにD1を巻き戻す必要はありません。

## Bot対策と費用

- Turnstileの成功、hostname、actionをサーバーで検査。秘密キー不足、異なるOrigin、不正入力は拒否。
- 本文4KiB、個別10回/分・同一拠点120回/分、日500件の新規受入上限。
- Worker CPU 50ms、集計最大1,960件。診断に生成AIや有料外部APIを呼びません。
- 拠点ごとのリミッターは近似値。受入上限は攻撃リクエストの課金自体を止めるものではなく、アカウント全体を月5ドルに固定する保証はありません。

緊急停止は `RESEARCH_ENABLED=false` で再公開します。診断の閲覧は続けられます。
