## 体験と設計

成人向けのエンタメ性癖診断。添付の `nocturne.html` を視覚の基準に、短い24場面と五つの選択肢を持つ一つの診断へ変更しました。最初の自己イメージだけ一択、その後は惹かれる内容を最大二つ選びます。順番・選択数・性別・年代・気分から強さを加点しません。未回答を中間点やゼロへ変換しません。主導・委ね・翻弄する側・される側・甘やかす側・甘える側を独立に選べます。

候補成分や二つ名は初期仮説です。性癖の完全な網羅、無意識の測定、心理検査としての妥当性、関係の成功率は主張しません。繰り返した選択と回答の機会を見て名前を作り、一つの選択だけで強い結論を出しません。16の関係性は、診断の分類数ではなく読みものの図鑑です。

入口、質問、カルテを画面内に収める構成。結果は名前・好み・接し方・記録・共有の5ページです。小さい高さや拡大時には内容を切らずにスクロールを許します。動きを抑える設定にも対応します。質問の日本語は意味を保って短くし、BudouXと保護する語句で改行を整えます。診断画面に内部の点数や運用仕様は出しません。

## 主なファイル

- `src/nocturne-service.mjs`, `migrations/0005*`, `0006*`: D1の記録、ログイン、短いURL、募集、相互反応、ブロック、通報、集計、期限処理。

## 記録とログイン

開始前に成人確認と回答提供の同意を取ります。提供せず端末だけで試す経路もあります。同意後は登録画面を挟まずに匿名の記録を作り、HttpOnly・Secure・SameSite=StrictのCookieで本人の履歴だけを読み書きします。引き継ぎキーは本人が発行を選んだときに一度だけ表示し、保存先にはハッシュだけを残します。別の端末からキーでログインできます。キーは共有URLとは別です。

回答は4場面ごと・中断時・完了時に同期し、通信できない間は端末に残します。古い更新が新しい更新を上書きせず、完了した記録を変更しません。アカウント切り替え時は同期を中断し、端末の記録を分離します。API側でも更新対象の所有者とアカウントの一致を確認します。

「最近の自分」「今の自分」は同じ質問票の時間の文脈です。気分や時間帯は記録し、結果を補正する材料にはしません。履歴に架空の過去や仮の基準点を作らず、同じ文脈の実際の記録を比べます。

## 短いURLと匿名募集

共有は画像で内容を確認してから、`/s/`と96bitのランダムな識別子を持つURLを発行します。公開用の二つ名・短文・説明・選んだ3タグと主な好みだけを保存し、個別回答、年代、性別、履歴を含めません。共有リンクはnoindex・no-storeで、90日で期限が切れます。

匿名の募集一覧は、提供した診断を完了し、半分以上の場面に回答した利用者が閲覧できます。本人が選んだカルテだけを明示同意後に7日間掲載します。年代・性別は追加で表示を選ぶ方式。自由タグ・自由な募集文・写真・場所・連絡先・DMは公開しません。

共通する好み、役の組み合わせ、個別の好み、相手の目的、公開された年代・性別で絞れます。双方が「気になる」を選ぶと掲載したカルテ同士を比較します。成功率は出しません。掲載の撤回、更新、ブロック、期限切れで相互反応を無効にします。非表示は本人の管理画面から解除できます。通報は相手を非表示にし、3人からの通報で掲載を確認待ちにします。再掲載や通報者の削除で確認待ちを回避できない状態を保持します。

## 分析と運営

15分ごとに、同意した利用分の直近7日・新しい2,000件までを集計し、R2の非公開`owner/nocturne-current.json`を更新します。場面の閲覧、回答、滞在時間の中央値、30分以上進んでいない位置、年代・性別、気分・時間帯、選んだ好みを分けます。同意前の訪問は未測定（null）です。中断は離脱の確定ではなく、再開で変わります。

人数は同じ人を重複して数えず、各属性群と各好みについて5人未満は表示しません。一般人口の割合、原因と結果、マッチングの成功率は推定しません。集計から質問や分類を自動で書き換えません。


## 保存期間・復旧・費用

回答180日、途中の記録30日、ログイン状態30日、共有90日、募集7日、長期間使われないアカウント1年を目安に削除します。回答提供の撤回はアカウントに属する回答・履歴・ログイン状態・共有・掲載を削除します。R2の回答を含まない削除の控えを先に保存し、失敗時に削除済みと表示しません。

D1の復旧前は`RECOVERY_MODE`を新しいUUIDにして受付・共有を止めます。以前の`withdrawals/`に加え、`nocturne-withdrawals/`と`nocturne-record-withdrawals/`を再適用します。各`nocturne-recovery/<UUID>/`の完了と、既存の`maintenance`の完了を確認してから停止を解除します。画面のロールバックにD1の巻き戻しは不要です。

Turnstileの成功・hostname・action、Originと専用ヘッダー、本人の所有権をサーバーで確認します。本文8KiB、個別10回/分、拠点ごと120回/分、日500診断開始・10,000書込みの正確な上限を持ちます。書込み上限はSQLiteのトリガーで制御し、再試行で越えられません。CPUは最大250ms、定期集計の読込みは最大2,000件。集計を一度だけ解析するようにし、上限件数のローカル負荷も確認しています。生成AIや従量課金の外部AI APIは使いません。これらはアカウント全体の月額を5ドルに固定する保証ではありません。

`RESEARCH_ENABLED=false`で新しい受付・更新・掲載を止められ、撤回・非表示・ログアウトは続けられます。未取得の広告IDは有効にせず、診断中に広告を出しません。
