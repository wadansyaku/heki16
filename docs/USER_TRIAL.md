# 対象者の試用：初回5人の準備

対象は18歳以上・高校生を除き、日本語の自己理解・診断コンテンツに関心がある人。うち3人程度は「S/Mだけでは好みを表しにくい」という課題を自分で感じている人、残りは一般的な診断コンテンツの利用者を目安とする。5人は募集目標であり参加実績ではない。母集団の割合・統計的な妥当性の証明には使わない。謝礼・有料サービス・自動勧誘は使用しない。

## 最初に決めること

- 今回の問い：初めての人が、何をするサイトか、回答提供と匿名掲載が必須であること、掲載・共有される範囲を理解して操作できるか。
- 1人20〜30分を目安にする。完了を強制しない。途中辞退も重要な観察結果として扱う。
- 本番 https://kuseiro.com/ を本人の端末で使う。本番の通常条件（回答提供・匿名掲載必須）を隠さない。掲載に同意できない人には診断開始を求めない。
- 研究協力は任意。サイト利用の必須同意と、試用への協力を混同しない。Xへの投稿も任意で、投稿完了を試用の条件にしない。
- 自分の回答を見せる必要はない。回答中は画面共有・録画・スクリーンショットを止める。見せたくない場合、操作の終了・困りごとだけ本人に報告してもらう。
- 連絡先、氏名、Xアカウント、原回答、性癖、結果の二つ名、公開タグ、共有URL、引き継ぎキーを観察記録へ入れない。協力者はT01〜T05で扱い、対応表を作らない。外部のAIへ試用の生データを送らない。
- 年齢条件は本人の表明だけを確認し、生年月日・学校名・身分証は集めない。条件を満たさない人には内容を見せず終了する。

## 協力者へ渡す案内

> KUSEIROの画面の使いやすさを確かめる、20〜30分ほどの試用にご協力いただける方を探しています。対象は18歳以上・高校生を除く方です。サイトで診断結果を見るには、回答提供と匿名カルテの掲載への同意が必要です。公開前に内容を確認でき、掲載は取り下げられます。試用は途中でやめられ、回答内容・結果・画面・連絡先は試用記録に残しません。使いにくかった点だけ伺います。Xへの投稿は必要ありません。

これは送信用の完成案。まだ誰にも送信していない。

## 進行役の台本と課題

冒頭：「あなたの好みを評価する試用ではありません。画面を確かめています。困った場合は手伝えますが、最初は説明を足さずに見守ります。回答内容は見せなくて構いません。匿名掲載に同意できない場合はここで終了できます。」

| 課題 | 本人への依頼 | 観察すること | 完成・終了の条件 |
|---|---|---|---|
| H：ホーム | 何ができるサイトか、次に何をすると思うか教えてください | 対象・価値・流れを本人の言葉で説明できるか | 画面にある文をそのまま読ませない。期待した結果とのずれを記録 |
| C：開始前 | 開始画面を見て、利用に必要な同意と公開されるものを説明してください | 年齢確認と利用同意の違い、掲載が必須と分かるか | 納得できなければ辞退。誤認している場合は説明して止め、同意させて先へ進めない |
| Q：診断 | 回答を一つ選び、戻る・保留・中断と再開を試してください | 選択数、保留、戻る、再開の理解。読みにくさ・疲れ | 回答内容は取得しない。時間は操作の開始・終了だけ記録 |
| P：掲載前 | 公開カードで、他の人に何が見えるか確かめてください | 原回答・年代・身体視点・公開タグと、共有リンクとの区別 | 内容を理解して本人が決めるまで掲載操作を促さない |
| R：結果 | 結果が何をもとに作られたと思うか、分かりやすさを教えてください | 確定的な判定や医学的な診断と誤解しないか。選んだ場面とのつながり | 好みの内容は聞かず、「説明できた／説明が難しい」を記録 |
| S：共有 | 公開カードの内容を確認し、Xでシェアするを押してください | Xへ直接進めるか、自由タグ・個別回答が含まれないか、投稿はXで確定するとの理解 | Xへの実投稿は求めない。作成したリンクの無効化も確認 |
| D：図鑑 | 自分の二つ名と、未判定の説明を図鑑で探してください | 診断と図鑑の名前の一致。未判定を別のタイプや順位と誤認しないか | 結果や個人の好みは記録しない |
| W：取り下げ | 掲載の取り下げと、回答提供の撤回の場所を探してください | 違いを理解し、必要な操作にたどり着けるか | 本人の希望で実行。研究終了を理由に本人の通常の履歴を一括削除しない |

終了時は「どこで迷ったか」「期待と違った点」「もう一度使いたい場面があるか」「他の診断と違うと感じた点」を聞く。機能名・結果の内容へ誘導しない。発言の引用は本人が確認した、機微情報を含まない要約だけにする。掲載を続けるか取り下げるか、提供を撤回するかを本人に選んでもらう。保存・転送済みの画像まで消せるとは説明しない。

## 記録方法と判定

`trial-observations.csv` の空の記録票を使う。列は「協力者ID、サイト版、端末、ブラウザー、課題、結果、補助、所要秒数、理解、確認方法、問題、優先度」。1行1課題で、実際に試用してから記入する。

- 結果：完了／辞退／中断／未実施／不明。同意しないことを「失敗」としない。
- 補助：なし／声かけ／操作の補助／不明。説明してできた場合を自力完了に数えない。
- 理解：説明できた／一部あいまい／誤認あり／未確認。実際に説明してもらった場合だけ記録。
- 確認方法：直接観察／本人の報告／不明。画面を見ていない操作は本人の報告として扱う。
- 所要秒数：測っていなければ空欄。0秒に置き換えない。端末・ブラウザーも未取得は不明。
- 問題：結果・好み・氏名を含めず、操作上の問題を短く記述。優先度はP0/P1/P2/問題なし/不明。

必須掲載・公開範囲の重大な誤認、意図しない公開、撤回できない問題が1件でも見つかったら、該当する試用を中断しP0として再現・修正する。集客の拡大と自動採用を止める。回答内容は再現に使わず合成データへ置き換える。

最初の3人で一度整理し、同じ操作で繰り返す詰まりを修正してから残り2人で確かめる。全員が自力で操作できても、実機・年齢条件・公開範囲の未確認は残す。5人の率を全利用者へ一般化しない。分類の再現性・心理学的妥当性・売上は今回の合否に含めない。

試用の観察メモは集約後30日以内に削除し、個人と結び付かない問題・再現手順・完成条件だけ残す。修正案は `tools/improvement/intake.mjs` の出典・反対例・最小要件・完成条件に整理し、人が優先度と採用を決める。実参加がない間は未実施と記録し、合成試験を実利用者の声に数えない。

## 追加課金なしの機械確認

既存テストとブラウザー確認は `npm run improvement:product-demo -- --output <新しい外部フォルダ> --playwright-module <導入済みplaywrightの絶対パス> --browser <導入済みChromiumの実行ファイル>` で実行する。依存やブラウザーを自動インストールしない。合成のCSS変更で主ボタンを隠す候補を不合格にし、元のCSSに戻す候補を合格にする。試用手順の操作に相当する年齢確認・必須同意・24場面・公開・結果・共有・撤回を、ローカルDBだけで通す。

この試験を対象者の試用、実iPhone/Safari、読み上げ評価、実Claudeによる実装の成功とは数えない。本番の回答・掲載・利用集計は変更しない。myfansの公開条件は公式回答に基づく規約・ガイドラインへの適合確認とし、現行の配信制御を維持する。試用で購入や成果発生を求めない。
