# 画面設計

参照: home-concept.png / result-concept.png。生成画像を配置するのでなく、実際に操作できる画面として実装する。

- 背景 #13111b、面 #1b1826、文字 #f4f0fa、副文字 #bcb4ca、アクセント #b99ae6。発光、点滅、装飾的なアニメーションを使わない。
- 本文16px以上・行間1.8、本文幅最大68文字程度。短い語を無理に均等分割せず、日本語の禁則処理に従う。見出しの改行は意味の区切りのみ。
- トップ: 目的、開始、2つの長さ、3つの読み物。結果: 要約、3つの開閉行、自由タグ、共有。詳細は必要になったときに開く。
- タグは24個まで、32文字以内。好きと境界線を分ける。表記を整え、自動分類し、ユーザーの修正をその端末で覚える。共有は明示的な選択式。
- 病名、科学的に検証されたタイプ、相性成功率、人口順位を示さない。根拠・限界は独立した読み物に置く。
- 旧版の保存データとコードは旧版で読み出せるよう保持する。

本文には対応ブラウザーで `word-break: auto-phrase` を適用。重要な見出しと短い説明は文節のまとまりで保持し、未対応のブラウザーでも見出しが分断されにくい構造にする。[Googleの解説](https://developers-jp.googleblog.com/2023/09/budoux-adobe.html)。iPhone/Safariの実機確認は別途必要。
