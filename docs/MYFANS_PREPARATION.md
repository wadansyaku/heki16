## 承認後に有効化する手順

1. アフィリエイター登録とNOCTURNE媒体の承認を確認する。
2. 実際の表示文と表示位置、任意の回答活用を含む説明についてmyfansの確認を受け、記録を手元に残す。素材を使う場合は別に権利者の許諾を得る。
3. NOCTURNE用として管理画面で生成したリンクを取得する。追跡先のホスト名を正確に確認し、利用者の回答や識別子を付け足さない。
4. `config/monetization.json` の `allowedHosts` に確認済みのホストを登録し、`campaigns` に承認済み文言と取得済みURLを設定する。1件から開始する。
5. 各広告に `creativeApproved:true`、`linkVerified:true`、確認日時 `reviewedAt`、次の再確認期日 `expiresAt`、`placements:["post-share"]`、`affinities:[]` を設定する。未承認のものは `enabled:false` とする。`expiresAt` は運営側の再確認期限であり、myfansが約束するリンク有効期限ではない。
6. `siteApproved:true` と `enabled:true` にする。回答を使った表示調整も承認された場合だけ `personalizationEnabled:true` にし、広告に対応する既存の好みIDを `affinities` に設定する。一般表示ならfalseのまま使える。
7. `npm run verify`、ローカルでスマホ幅の診断→共有→PRの検証を行う。未同意/同意/解除、受け取った結果、期限切れ、計測拒否を確認してから通常の公開手順で反映する。
8. PR入口のクリックとmyfans側のクリック・確定成果を確認する。購入や自己アフィリエイトを自動実行して成果テストをしない。

無効化は `enabled:false` に戻して再ビルド・公開します。閲覧中の古いページは即時に遠隔変更されません。再確認期日を過ぎた広告は、開いたままのページでも表示/遷移を止めます。

設定項目の形（架空のURLを公開しない）:

## 計測と判断

- 所有者の管理画面に「PRの紹介を開いた」「PRリンクを押した」を追加。30分のタブ単位で同一操作を重複加算しない件数であり、総クリック数・実人数・myfansへの到着・購入数ではありません。
- 診断回答、二つ名、年代、性別、広告ID、リンクURL、回答活用のオン/オフを計測APIへ送りません。既存の匿名計測だけを利用し、DNT/GPCに従います。
- 成果/返金/確定報酬はmyfans側のレポートで確認します。NOCTURNEに架空の売上や成約率を出しません。
- 診断完了・共有の利用状況と併せて判断します。自己選択による違いを、広告が離脱を引き起こしたという因果関係と断定しません。

広告設定が無効、承認未確認、リンク未取得、再確認期限切れならPR入口そのものを出しません。空の広告枠・審査待ち・設定値などはユーザー画面に出しません。
